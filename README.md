# hudson-fleet

내 PC에서 돌고 있는 Claude Code 세션들을 한 화면에서 보는 로컬 대시보드입니다. 에이전트가 한 일을 작업 단위로 기록하고, 프로젝트별로 묶어 봅니다.

## 설치

Claude Code 에서 입력합니다.

```
/plugin install hudson-fleet --marketplace hava12/hudson-fleet
```

Claude Code 2.1.275 이전이면 두 단계로 설치합니다.

```
/plugin marketplace add hava12/hudson-fleet
/plugin install hudson-fleet@hudson-fleet
```

- 필요한 것: Python 3.9 이상(시스템 `python3`), PATH 에 있는 `claude` CLI. 따로 설치할 패키지는 없습니다.
- Claude Code 세션을 하나 열면 대시보드가 함께 뜹니다. 브라우저에서 http://127.0.0.1:8765 를 엽니다.
- 업데이트: 새 버전이 설치되면 대시보드 위쪽에 [새 버전으로 바꾸기] 가 뜹니다. 누른 뒤, 이미 열려 있는 세션에서는 `/reload-plugins` 를 합니다.

## 사용법

### 작업 기록

설치만 하면 에이전트가 일을 시작하고 끝낼 때마다 스스로 기록합니다. 따로 할 일은 없습니다. 기록은 대시보드의 남은 작업, 세션 패널, 세션 기록에 보입니다.

### 화면

| 메뉴 | 하는 일 |
| --- | --- |
| 현황 (왼쪽 위 로고) | 살아 있는 세션 그래프와 상태별 숫자, 남은 작업(프로젝트별로 골라 보기). 세션을 누르면 오른쪽에 그 세션의 작업과 push 가 나옵니다 |
| PARA | 프로젝트(이름과 완료 조건)와 영역을 만들고, 프로젝트별 작업과 기획명세서를 봅니다. [숨기기] 를 누르면 그 프로젝트의 할 일이 화면에서 보이지 않습니다 |
| History | 끝난 세션(이어서 열기·복사해 열기)과 push 기록 |
| 예약 작업 | Claude 예약 작업(루틴)과 세션에 걸어 둔 예약 |
| 이슈·PR | 나에게 할당된 Jira 이슈(새 에이전트에게 맡기기)와 GitHub PR |
| MCP 서버 | 연결된 MCP 서버의 상태 |
| 설정 ⚙ | 연결(GitHub·Jira·Obsidian)과 작업 정리·터미널 같은 설정 |

옵시디언에도 기록하려면 설정 ⚙ → 연결 → Obsidian 에서 [사용] 을 켜고 볼트 안의 폴더를 넣습니다. 1분마다 세션과 프로젝트 노트를 씁니다.

### 채팅에서 부르기

| 이렇게 말하면 | 하는 일 |
| --- | --- |
| "사전 기획 시작해 줘", "기능 하나 추가하고 싶어" | 프로젝트를 만들거나 기능을 검토해 기획명세서에 적습니다 |
| "기획명세서 만들어 줘" | 코드와 작업 기록으로 기획명세서를 만들거나 고칩니다 (PARA 의 [명세서 업데이트] 와 같음) |
| "MVP 정해 줘", "명세서로 데모 만들어 줘" | 첫 판 범위를 정하고 데모로 확인합니다 |
| "이 프로젝트 적합성 평가해 줘" | 할 만한 일인지, 만든 기능이 목적에 맞는지 평가합니다 |
| "이거 자료로 남겨 줘" | 대화 내용을 PARA 자료로 남깁니다 |
