# hudson-fleet

내 PC에서 돌고 있는 Claude Code 세션들을 한 화면에서 보는 로컬 대시보드입니다.

프로젝트 → 세션 → 서브에이전트 → 편집한 파일을 DAG(방향 비순환 그래프)로 그립니다.

## 실행

```sh
python3 server.py   # → http://127.0.0.1:8765
```

- Python 3.9 이상, 표준 라이브러리만 씁니다.
- `claude` CLI가 PATH에 있어야 합니다.
- 그래프 라이브러리(cytoscape, dagre)는 CDN에서 받으므로 인터넷 연결이 필요합니다.

## 기능

- **세션 현황**: `claude agents --json --all` 결과를 5초마다 새로 그립니다. 테두리 색으로 상태를 구분합니다.
- **노드 클릭**: 세션은 마지막 답변, 파일은 내용을 보여 줍니다.
- **우클릭**:
  - 세션 화면으로 이동: 세션을 띄운 터미널이나 IDE를 앞으로 가져옵니다.
  - 세션 종료
- **실행**: 작업 폴더와 할 일을 넣으면 `claude --bg`로 백그라운드 에이전트를 띄웁니다.

## 보안

- 서버는 `127.0.0.1`에서만 열립니다.
- 다른 출처(Origin)에서 오는 POST 요청은 거부합니다.
- 파일 열람은 그 세션이 편집한 파일만 허용합니다.
- 종료는 `claude agents` 목록에 있는 세션만 할 수 있습니다.

## 한계

- 종료된 대화형 세션은 보이지 않습니다. `claude agents`가 살아 있는 세션과 백그라운드 작업만 돌려주기 때문입니다.
- IntelliJ 안의 세션은 프로젝트 창까지만 이동합니다. 터미널 탭은 고르지 못합니다.
